ONLINE KULLANIM BILGISI

Bu uygulama tarayici guvenlik kisitlamalari (CORS) nedeniyle dogrudan bilgisayarinizdan calismayabilir. Asagidaki adimlari takip edin:

  1. GitHub Pages (Ucretsiz): Dosyayi GitHub'a yukleyip Settings > Pages > Deploy from branch (main) secin. Site aninda online olur.
  2. Netlify Drop (Ucretsiz): app.netlify.com/drop adresine gidip dosyayi surukleyip birakin.
  3. Yerel Sunucu: Terminalde python -m http.server 8000 veya npx serve calistirin, sonra http://localhost:8000 acin.

Not: CORS kisitlamasi olmadan canli veri cekmek icin uygulamayi mutlaka bir web sunucusunda (GitHub Pages/Netlify) calistirin.
